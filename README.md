# naman.dev — Portfolio

Personal portfolio of **Naman G Shetty**, Senior Salesforce Developer & AI Platform Engineer.

Live: **https://shettynamanoct4-lang.github.io**

Built with React, TypeScript, Vite, Tailwind CSS and Framer Motion. Deployed to GitHub Pages via
GitHub Actions on every push to `main`. All content lives in [`src/data.ts`](src/data.ts).

```bash
npm install
npm run dev     # local dev server
npm run build   # production build to dist/
```
